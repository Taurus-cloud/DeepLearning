# DeepLearning Learning Notes

Small PyTorch learning experiments. This repository is intentionally kept separate from the optimization and algorithm-engineering projects featured on the profile.

## Included Experiment

`PyTorch/` contains a phone-price classification exercise with:

- CSV data loading and a stratified train/test split
- A feed-forward PyTorch classifier
- Training and evaluation routines
- Saved model-weight files from the experiment

The scripts are learning artifacts, not a production machine-learning system or a benchmark claim.

## Quick Start

```bash
python -m pip install -r requirements.txt
cd PyTorch
python 'ANN案例_手机价格分类.py'
```

The checked-in script runs its evaluation path by default. Its training function is included in the same file and can be enabled for experimentation.

## Scope

This repository is not a featured portfolio project and should not be pinned. It remains available as a concise record of foundational PyTorch practice.
